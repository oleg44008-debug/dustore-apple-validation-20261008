# DustoreX · iOS 1.2.0, build 3

Изолированная копия SwiftUI-приложения для iPhone и iPad, iOS 16 и новее. Новый исходный код требует нативной проверки Xcode: грамматический разбор на Windows не проверяет типы SwiftUI, SDK, подпись или поведение на устройстве. Предоставленный IPA в папке `../../iPhone/` сохранён без изменения.

Обновление включает зрелую obsidian/lavender/citrus дизайн-систему, iPad sidebar и адаптивную полку, поиск и сортировку, избранное и переименование, подтверждение удаления, прямые действия импорта на eX и пустом экране. На iPad сохранена штатная панель навигации: её кнопка открывает разделы, даже когда система сворачивает боковую панель. Dynamic Type перестраивает карточки; при размерах для доступности кнопка импорта закреплена над нижней безопасной областью и остаётся доступной во время прокрутки. Reduce Motion убирает пространственное движение, выключенные анимации дают мгновенный отклик. Фон статичен; в покое нет анимационных таймеров.

Импорт владеет своей задачей и источником: показывает реальный этап, отменяется между блоками копирования/распаковки/сети, очищает незавершённую игру, сохраняет источник при ошибке и предлагает повторную попытку. Неподдерживаемая сборка получает честное объяснение. Сетевой движок скачивается по проверенным диапазонам, неполный кэш исправляется повторной загрузкой. Free сохраняет прежние лимит, очередь и скорость; отмена или ошибка не расходуют квоту. Prime работает без этих ограничений.

Магазин отображает состояние WebKit и автономную ошибку с повторной загрузкой. `WKDownload` отслеживает реальные байты, поддерживает отмену и возобновление, когда WebKit предоставляет resumeData. Сессия загрузки принадлежит библиотеке и сохраняет управление при перестройке интерфейса iPad; для повтора без открытого магазина она создаёт временный собственный WKWebView. Загруженный файл удаляется только после успешного импорта. Если возобновление недоступно, файл остаётся в папке приложения; загрузку можно повторить из магазина.

Игрок показывает настоящие состояния страницы/движка, ошибки и перезапуск. Экранные кнопки поддерживают одновременные удержания; геймпад передаёт WASD/стрелки, Space, E, Enter и Escape через адаптер клавиатуры в реальную веб-игру. При закрытии, отмене касания, смене раскладки, отключении устройства и уходе в фон удержания освобождаются. Финальное закрытие идемпотентно: повторный teardown и поздние callbacks не возобновляют ввод, а внутреннее состояние клавиш не публикуется во время перестройки SwiftUI. Bluetooth-клавиатура работает напрямую через WebKit. Поддержка зависит от самой игры; это не универсальный эмулятор. Игровое меню явно объясняет, что логика веб-игры продолжает работать.

## Free и Prime

`project.yml` содержит конфигурации `FreeDebug`, `FreeRelease`, `PrimeDebug`, `PrimeRelease` и явные схемы `DustoreX-Free` / `DustoreX-Prime`. Только Prime добавляет `PRIME`; существующая модель отдельной редакции и bundle ID `ru.dustore.launcher.ios` сохранены. Активация из внешней ветки не добавлялась. Конфигурация по умолчанию в папке Prime — `PrimeDebug`, в отдельной копии Free — `FreeDebug`. Для воспроизводимой сборки всегда выбирайте явную схему и конфигурацию.

## Сборка и проверка на Mac

Нужны macOS, Xcode 16.4 или новее и XcodeGen. Современный SDK нужен для символа `isInspectable`; он защищён проверкой iOS 16.4, а минимальная версия приложения остаётся iOS 16.0.

```sh
xcodegen generate
xcodebuild -project DustoreX.xcodeproj -scheme DustoreX-Prime \
  -configuration PrimeDebug -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
bash Scripts/validate-apple.sh
```

Для Free выберите `DustoreX-Free` и `FreeDebug`. Полный скрипт собирает/анализирует обе редакции Debug и Release, строит неподписанные версии для device SDK и запускает native XCTest/XCUITest. Инструкции, покрытия тестов, ограничения и переменные для выбора iPad/iPhone описаны в [VALIDATION.md](VALIDATION.md). Скриншоты и результаты остаются в `.xcresult`; синтетические диагностические данные включаются только явным аргументом в debug-сборке.

Подписанный установочный IPA требует команды подписи и provisioning в Xcode. `Scripts/package-unsigned-device.sh` упаковает только уже собранный device Release и явно помечает результат `UNSIGNED`; такой файл требует подписи для установки. Не заменяйте исходный IPA этим диагностическим пакетом.

AppIcon использует подлинный `BrandMark` на непрозрачном квадратном фоне. Для воспроизводимого формирования ресурса на Mac выполните `xcrun swift Scripts/generate-app-icon.swift`: скрипт оставляет исходный PNG без изменений, размещает его в исходном разрешении и проверяет отсутствие прозрачности у иконки 1024×1024. Системную маску скругления применяет iOS.

Перед выпуском дополнительно проверить на физических iPhone/iPad: VoiceOver и Switch Control, Increase Contrast, максимальный Dynamic Type, Reduce Motion, портрет/альбом и Split View; одновременные касания, реальные Bluetooth-устройства, потерю сети и отмену каждого этапа, настоящие Godot 3/4 и веб-сборки. Производительность измеряется Instruments на реальном устройстве. Секреты, подпись и внешние оригинальные проекты не входят в эту копию.
