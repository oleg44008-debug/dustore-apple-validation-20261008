# DustoreX Prime · iOS source design update

Это изолированная копия нативного SwiftUI-приложения для iOS 16 и новее. Обновлены оформление и пользовательские настройки. Готовый файл `../../iPhone/DustoreX-iOS-prime.ipa` сохранён: эта копия исходников ещё не скомпилирована и не проверена на iPhone.

## Что изменено

- Obsidian-фон `#111116`, лавандовый выбор `#BEB0FF` и светлый цитрус `#ECF39A` для основного действия. Оригинальный логотип добавлен в asset catalog без изменения PNG.
- Мягкий отклик кнопок, появление карточек и короткие переходы. Системное **Уменьшение движения** отключает пространственное движение; настройка **Выключены** отключает анимации приложения. В покое нет таймеров, повторяющихся эффектов или частиц.
- Библиотека с поиском, реальными счётчиками и фильтром готовых игр, заметным запуском недавно добавленной игры и пустым состоянием без выдуманных игр. Удаление игры подтверждается перед удалением её файлов.
- Настройки анимаций, тактильного отклика и компактных карточек сохраняются в `UserDefaults`. Dynamic Type увеличивает текст; при размерах Accessibility карточки сохраняют полный размер. Кнопки имеют область нажатия не менее 44 pt.
- Обновлены экраны eX, магазина, выполнения переноса и выхода из игры. Логика движков, импорта, веб-игр и хранения библиотеки сохранена.

## Редакция Prime

`Edition.swift` использует прежнюю отдельную редакцию `#if PRIME`. В `project.yml` есть четыре конфигурации: `FreeDebug`, `FreeRelease`, `PrimeDebug`, `PrimeRelease` и две явные схемы `DustoreX-Free` / `DustoreX-Prime`. Только Prime-конфигурации добавляют `PRIME` в `SWIFT_ACTIVE_COMPILATION_CONDITIONS`; идентификатор пакета `ru.dustore.launcher.ios` сохранён. В этой папке Prime конфигурация по умолчанию — `PrimeDebug`; отдельная копия исходников Free сохраняет `FreeDebug`. Для сборки этой версии выбирайте схему **DustoreX-Prime**.

Новая проверка покупки из более поздней внешней ветки не переносилась: `PrimeLicense.swift`, повторная активация и интерфейс активации отсутствуют. Это сохраняет модель предоставленного отдельного Prime IPA. Проверка читаемых строк исходного Mach-O не обнаружила `PrimeLicense`, `activate`, `license/`, `redeem` или `isPrimeBuild`; отсутствие строк в собранном бинарнике само по себе не доказывает полный состав его исходников.

## Нативная сборка

Нужны **macOS, Xcode с iOS SDK 16+ и XcodeGen**. На Windows отсутствует Apple SDK; проверка текста не заменяет компиляцию SwiftUI и запуск приложения.

Из этой папки на Mac:

```sh
xcodegen generate --spec project.yml
xcodebuild -project DustoreX.xcodeproj -scheme DustoreX-Prime \
  -configuration PrimeDebug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
open DustoreX.xcodeproj
```

Для Free используйте схему `DustoreX-Free` и конфигурацию `FreeDebug`; в таком приложении `Edition.isPrime` остаётся `false`.

Для физического iPhone выберите схему **DustoreX-Prime**, свою команду подписи в Xcode и устройство назначения. Архив и установочный IPA создаются через **Product → Archive** и подходящий способ подписанного экспорта. Исходная версия IPA — 1.0.0; версия обновлённых исходников — 1.1.0, build 2. Не заменяйте исходный IPA до успешной нативной проверки и подписи новой сборки.

## Проверки перед выпуском

1. Скомпилировать Debug/Release с `PRIME` и убедиться, что приложение показывает Prime без активации, а eX не включает ограничения Free.
2. Проверить узкий портрет, альбомный режим, iPad Split View и самый крупный Dynamic Type: заголовки, фильтры, поиск, меню, кнопки, импорт и настройки должны оставаться доступными без обрезки.
3. Включить Reduce Motion в iOS: появление карточек становится коротким растворением, отклик кнопок не меняет масштаб. Проверить режимы полные / короткие / выключены и сохранение выбранных настроек.
4. VoiceOver должен читать названия игр, статусы, даты, поиск, очистку поиска и кнопку выхода из игрока. Проверить контраст при системном Increase Contrast.
5. Импортировать собственную поддерживаемую Godot-игру и веб-игру, запустить, закрыть, перезапустить приложение и проверить сохранение библиотеки. Проверить сообщения Unity/C# и отмену удаления.
6. После нативной проверки создать подписанный архив. Только этот проверенный результат может заменить доставляемый IPA.

Скопированы только необходимые файлы `App`, `project.yml` и оригинальный логотип. Выходные сборки, CI-конфигурация, GitHub-настройки и лицензирующий сервис не включены.
